AlgoPilot Windows x64 便携版使用说明
====================================

1. 将 ZIP 完整解压到本地磁盘，建议使用 C:\AlgoPilot 等纯英文路径。
2. 双击“Start AlgoPilot.bat”或“Run AlgoPilot.bat”，不要直接打开
   AlgoPilot.exe。
3. 等待默认浏览器自动打开，并保留当前服务器窗口。程序异常退出时，
   该窗口会显示退出码并等待按键，不会自动关闭。
4. 使用结束后，关闭服务器窗口即可停止服务。

目标电脑无需安装 Python、Node.js、数据库、g++ 或 gdb。

数据与备份
----------
- data\alp_learning.db 是打包时生成的一致性 SQLite 完整快照。
- PACKAGE_MANIFEST.json 记录数据库 SHA-256、表名和每张表的行数。
- 新账号、学习记录和提交记录会继续写入该数据库。
- 备份前请关闭程序，然后复制整个 data 目录。

联网功能
--------
- 账户、课程、进度、题库、C++ 判题和 Trace 可在本机运行。
- 星火大模型与讯飞语音合成本身需要网络及有效 API 凭据。
- .env 保留打包时配置；发给不受信任的人之前应移除或更换密钥。

注意事项
--------
- 本包面向 64 位 Windows 10/11；不同操作系统需要分别构建。
- 目录名可以包含空格，但不要包含中文或其他非 ASCII 字符；随包 MinGW
  编译器在非 ASCII 安装路径下无法可靠定位自身运行库。
- Windows Defender 首次扫描编译器和程序时可能需要较长时间。
- 不要只复制 exe；_internal、data、mingw 目录均为必需内容。
