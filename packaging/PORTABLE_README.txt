AlgoPilot 便携版使用说明
========================

1. 将压缩包完整解压到本地磁盘（路径中可以包含中文或空格）。
2. 双击“启动 AlgoPilot.bat”。
3. 等待默认浏览器自动打开。请保留“AlgoPilot Server”窗口。
4. 使用结束后，关闭“AlgoPilot Server”窗口即可停止服务。

无需安装 Python、Node.js、数据库、g++ 或 gdb。

数据说明
--------
- data\alp_learning.db 是随包附带的完整 SQLite 数据库。
- 程序运行产生的新账号、学习记录和提交记录会继续写入此文件。
- 备份时请先关闭程序，再复制整个 data 目录。

联网功能
--------
- 普通课程、账户、学习进度、题库、C++ 判题和 Trace 工具可在本机运行。
- 星火大模型与讯飞语音合成功能本身需要访问互联网及有效 API 凭据。
- .env 中已保留打包时的项目配置。若要分发给不受信任的人，请先更换或移除 API 密钥。

常见问题
--------
- Windows Defender 首次运行可能扫描较久，请等待扫描完成。
- 请勿只复制 bat 或 exe；_internal、data、mingw 目录都是必需的。
- 若浏览器未自动打开，可在启动窗口查看实际地址并手动访问。
