## 六、未能运行的测试及原因

### 6.1 msys2 python 环境问题（已解决）

- 现象：直接执行 `python -m pytest` 时，默认 python 指向 `H:\Dev\msys2\ucrt64\bin\python.exe`（msys2 版本，无 pytest/pip 模块）
- 原因：msys2 python 与系统 Python 解释器隔离，未安装 pytest
- 解决：切换到 `H:\App\python.exe`（pip 所属解释器，已安装 pytest）成功执行
- 已在 `03_测试说明书.md` 中添加环境说明注释，提醒后续执行者注意
