## 十一、已知限制

### 11.1 测试环境限制

| 限制 | 影响 | 缓解措施 |
|------|------|---------|
| C++ STL Trace 环境敏感性 | 该测试依赖宿主机 GDB 性能，在 CI 或低配环境下可能触发 3 秒硬上限超时；本次在 Windows 11 + MSYS2 ucrt64 环境下通过 | 生产环境建议 Docker 隔离 + 资源限制；已提供超时保护与能力不可用提示 |
| 测试无真实星火 API Key | LLM 相关功能需 mock | 已使用 mock 覆盖核心逻辑；真实 LLM 测试依赖手动验证 |
| 测试无真实讯飞 TTS | TTS 功能未覆盖 | TTS 为可选功能，不影响核心学习闭环 |

### 11.2 功能限制

| 限制 | 说明 | 升级路径 |
|------|------|---------|
| OJ 无进程级隔离 | 当前版本主要面向课程实验、竞赛展示和小规模教学试用；非生产级沙箱 | Docker 容器隔离 + seccomp |
| C++ 静态拦截可绕过 | 宏展开/模板元编程可绕过正则 | 接入 isolate/firejail |
| 无网络隔离 | OJ 子进程可访问外网 | Docker `--network none` |
| 无判题队列 | 同步判题影响响应 | Celery/RQ + 独立 worker |
| C++ STL Trace 环境敏感 | 该问题主要影响特定 Windows/GDB 环境下复杂 STL 容器的 C++ 动态追踪。Python Trace、基础 C++ 判题及普通变量追踪不受该问题影响。系统已提供超时保护和能力不可用提示，该问题被列为当前版本已知限制 | 生产环境建议 Docker 隔离 + 资源限制 |
| 生产部署能力不足 | 若用于正式生产环境，还需进一步完善容器级代码沙箱、并发判题队列、HTTPS、监控告警、数据库备份和高并发支持 | 参见 04_部署说明书.md |

### 11.3 测试覆盖盲区

| 盲区 | 原因 | 建议 |
|------|------|------|
| 真实 LLM 端到端 | 测试不消耗 API 额度 | 定期手动验证关键 LLM 流程 |
| 高并发场景 | 测试为单线程 | 压力测试工具验证 |
| 跨浏览器兼容 | 仅在开发环境验证 | BrowserStack 多浏览器测试 |
