# 第 8 章 排序算法专题

**chapter_id**: `ch08-sorting` · **module_keys**: `sorting`

## 学习目标

- 理解排序问题的输入、输出、比较模型与工程约束。
- 掌握冒泡、选择、插入、归并、快速排序与堆排序的核心过程。
- 能从稳定性、是否原地、时间复杂度与空间复杂度选择算法。
- 能使用 Trace 解释分区、合并、堆化和逆序对累计过程。

## 核心概念

### 排序问题定义

给定关键字序列 \(a_1,a_2,\ldots,a_n\)，按照非递减或非递增顺序重新排列。课程中既关注最终结果，也关注比较、交换、移动等基本操作，以及输入规模、重复元素和数据分布对算法的影响。

### 稳定性

若两个元素关键字相等，排序后仍保持原相对顺序，则算法稳定。冒泡、插入和归并排序通常稳定；选择、快速和堆排序通常不稳定。稳定性在“先按学号排序，再按成绩排序”等多关键字场景中很重要。

### 原地排序

原地排序通常指只使用 \(O(1)\) 或与递归栈相关的少量额外空间。插入、选择、冒泡和堆排序可原地实现；归并排序通常需要 \(O(n)\) 辅助数组；快速排序平均递归栈为 \(O(\log n)\)。

### 时间复杂度和空间复杂度

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 额外空间 | 稳定 |
|---|---:|---:|---:|---:|---|
| 冒泡排序 | \(O(n)\) | \(O(n^2)\) | \(O(n^2)\) | \(O(1)\) | 是 |
| 选择排序 | \(O(n^2)\) | \(O(n^2)\) | \(O(n^2)\) | \(O(1)\) | 否 |
| 插入排序 | \(O(n)\) | \(O(n^2)\) | \(O(n^2)\) | \(O(1)\) | 是 |
| 归并排序 | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n)\) | 是 |
| 快速排序 | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n^2)\) | 平均 \(O(\log n)\) | 否 |
| 堆排序 | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n\log n)\) | \(O(1)\) | 否 |

## 关键算法或数据结构

### 归并排序

归并排序采用“分解、解决、合并”的分治框架：递归排序左右区间，再用双指针线性合并。合并时若右侧元素先进入结果，可累计它与左侧剩余元素形成的逆序对数量。边界重点是半开区间的一致性和剩余元素回填。

### 快速排序

快速排序选择 pivot，将小于、等于、大于 pivot 的元素划分到相应区域，再递归处理子区间。随机 pivot 或三数取中能降低退化概率。快速选择只递归包含第 \(k\) 个元素的一侧，平均时间为 \(O(n)\)，适合 TopK。

### 堆排序

堆排序先在线性时间内自底向上建最大堆，再反复交换堆顶与末尾元素，并在缩小后的有效区间执行下沉。其最坏时间稳定为 \(O(n\log n)\)，额外空间 \(O(1)\)，但通常不稳定。

### 基础排序

- 冒泡排序：相邻逆序元素交换，可用“本轮是否交换”提前结束。
- 选择排序：每轮选择最小元素放到区间起点，交换次数少但不稳定。
- 插入排序：维护已排序前缀，适合小规模或近乎有序数据。

## 常见误区

- 快速排序分区后仍递归包含 pivot 的原区间，导致无限递归。
- 归并排序临时数组写回起点错误，或漏掉左右区间剩余元素。
- 逆序对使用 32 位整数累计，在大规模输入下溢出。
- 堆的左右孩子下标与有效长度混淆，`sift_down` 越界。
- 将“原地”误解为完全不使用递归栈，或误认为所有 \(O(n\log n)\) 排序都稳定。
- TopK 未明确第 \(k\) 小或第 \(k\) 大，快速选择目标下标计算错误。

## 课堂案例

- 对 `[5, 1, 4, 2, 8]` 展示冒泡排序每轮交换与提前结束标记。
- 对 `[7, 3, 5, 3, 9, 1]` 展示归并区间 `[0,3)` 与 `[3,6)` 的双指针合并。
- 对 `[6, 2, 8, 4, 7, 3]` 展示快速选择的 pivot、左右边界和目标下标。
- 对 `[4, 10, 3, 5, 1]` 展示最大堆建堆与堆顶交换。

## 实操练习

1. `sorting-basic-output`：读入整数序列，输出非递减排序结果。
2. `sorting-inversion-count`：用归并排序统计逆序对。
3. `sorting-kth-largest`：用快速选择或堆求第 \(k\) 大元素。
4. 比较近乎有序、小规模、重复值较多三类输入下的算法选择。

## 和 OJ/Trace 的结合点

- 归并 Trace：高亮 `left`、`mid`、`right`、`i`、`j` 和临时数组。
- 快排/快速选择 Trace：展示 pivot、分区边界与目标下标所在区间。
- 堆排序 Trace：用数组视图标记父子下标、有效堆长度和交换位置。
- 基础排序 Trace：记录每一轮比较、交换次数与不变式“后缀已就位”。
