# 第 4 章 字符串与双指针

**chapter_id**: `ch04-string` · **module_keys**: `string`, `two-pointers`

## 学习目标

- 掌握字符串遍历、子串判定与字符频次统计。
- 熟练对撞指针与滑动窗口模板。
- 能根据题意选择 \(O(n)\) 双指针替代 \(O(n^2)\) 暴力。

## 核心概念

- **字符串**：字符序列；长度、子串、前缀定义。
- **双指针**：同向（快慢）或相向（对撞）收缩搜索空间。
- **滑动窗口**：维护合法区间统计性质（最长/最短子串等）。

## 关键算法或数据结构

- 对撞指针：有序数组两数之和、盛水容器。
- 滑动窗口：无重复字符最长子串、固定窗口最大值。
- 字符哈希表：`dict`/数组计数。

## 常见误区

- 窗口收缩时未更新频次导致计数错误。
- Unicode 与 ASCII 题混用（课内以 ASCII 为主）。
- 空串、全相同字符边界未处理。

## 课堂案例

- 「无重复字符的最长子串」窗口右扩左缩过程。
- 有序数组「两数之和」为何能用对撞指针。
