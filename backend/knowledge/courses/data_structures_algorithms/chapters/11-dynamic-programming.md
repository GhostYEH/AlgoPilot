# 第 11 章 动态规划

**chapter_id**: `ch11-dynamic-programming` · **module_keys**: `dp`

## 学习目标

- 定义状态 `dp[i]`（或 `dp[i][j]`）含义与边界条件。
- 写出状态转移方程并实现自底向上填表。
- 区分线性 DP、背包、路径计数等入门模型。

## 核心概念

- **动态规划**：重叠子问题 + 最优子结构，记录子问题解避免重复计算。
- **状态**：刻画子问题规模的变量；**转移**：由更小状态推出当前状态。
- **空间优化**：滚动数组降低维度（一维 DP 压成两行）。

## 关键算法或数据结构

- 线性 DP：爬楼梯、打家劫舍（间隔选择）。
- 完全背包 / 0-1 背包入门。
- 路径 DP：网格 `unique-paths`，`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
- 记忆化搜索：自顶向下与填表等价。

## 常见误区

- 状态定义含糊导致转移错误。
- 初始化漏掉 `dp[0]` 或第一行/列。
- 把贪心题硬套 DP 或反之。

## 课堂案例

- 「不同路径」手填 3×3 表格。
- 零钱兑换：完全背包最少数硬币。
