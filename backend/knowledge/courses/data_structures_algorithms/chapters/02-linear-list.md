# 第 2 章 线性表（顺序表与链表）

**chapter_id**: `ch02-linear-list` · **module_keys**: `array`, `linked-list`

## 学习目标

- 掌握顺序表与链表的存储结构与操作复杂度对比。
- 能实现链表插入、删除、反转与合并有序链表。
- 理解虚拟头结点（dummy）简化边界处理。

## 核心概念

- **顺序表**：连续存储，随机访问 \(O(1)\)，中部插入删除 \(O(n)\)。
- **链表**：结点链式存储，按值查找 \(O(n)\)，已知前驱插入删除 \(O(1)\)。
- **线性表 ADT**：逻辑上相邻，物理实现可数组或链式。

## 关键算法或数据结构

- 单链表、双链表、循环链表（了解）。
- 快慢指针：找中点、判环。
- 数组双指针：原地移除元素、合并区间。

## 常见误区

- 链表删除时丢失前驱指针导致断链。
- 数组下标 off-by-one（`i < n` vs `i <= n`）。
- 反转链表时未保存 `next` 导致链表断裂。

## 课堂案例

- 「合并两个有序链表」与归并排序合并阶段的联系。
