# 第 5 章 树与二叉树遍历

**chapter_id**: `ch05-tree-binary-tree` · **module_keys**: `binary-tree`

## 学习目标

- 掌握二叉树前序、中序、后序、层序遍历（递归与迭代）。
- 理解二叉搜索树 BST 的有序性与查找复杂度。
- 能根据遍历序列恢复树或验证 BST。

## 核心概念

- **树**：结点 + 边；根、父、子、叶子、深度、高度。
- **二叉树**：每个结点最多两个孩子；空树是合法二叉树。
- **遍历**：按访问根结点时机分为先/中/后序；层序用队列。

## 关键算法或数据结构

- **二叉树遍历**：前序（根左右）、中序（左根右）、后序（左右根）、层序 BFS。
- 递归模板：先处理当前结点，再递归左右子树。
- 迭代中序：栈模拟递归路径。
- BST：左 < 根 < 右；中序遍历得有序序列。

## 常见误区

- 混淆前序与中序结果。
- 递归无空结点返回导致空指针。
- 全局变量记录前驱时 BST 验证写错。

## 课堂案例

- 对 5 结点小树手画四种遍历序列。
- 「最大深度」递归式 `1 + max(left, right)`。
